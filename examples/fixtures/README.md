# ONLY SYNTHETIC TEST FIXTURES

All numbers, intervals, groups, time stamps and regional squares under this folder are deliberately invented for automated testing. They **must not be used as empirical evidence**. The four-square GeoJSON does not portray any real geography. To use the skill in research, provide a documented, authorised real data source and your own chart config. `references/v2-data-contract.md` is the complete column/config contract.
