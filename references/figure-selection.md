# 以社会科学问题决定图型

默认优先展示 **数值、尺度和可比性**。漂亮不应让读者更难比较。

| 研究问题 | 首选图形 | 最重要的审查 |
|---|---|---|
| 描述一个变量的分布 | 直方图/ECDF/箱线图 | 区间、缺失、极端值、N；核密度带宽不宜掩盖离散性质 |
| 不同组的集中趋势与离散 | 点区间/箱线/小提琴 | 说明区间是 CI 还是分位数，不把误差棒当组内差异 |
| 地区、政府/组织排名 | 排序横条/点图 | 分母、年份、N；绝对量与人均量不可互换 |
| 30 年政策或财政趋势 | 折线/小多图 | 币值平减、统计口径、时间频率、断点与缺失 |
| 两时点/少量离散时期比较 | 斜率图/分组点图 | 不用折线制造中间连续趋势 |
| 结构构成 | 100% 堆叠条/堆叠条 | 分母一致，互斥且穷尽；多期比较需图例顺序一致 |
| 双变量相关 | 散点 + 有根据的拟合 | 相关≠因果；标注观测单位，防过绘与离群驱动 |
| 多指标 × 地区/年份 | 热力图/小多图 | 统一标准化的含义，不能用色彩隐藏原始尺度 |
| 模型结果比较 | 系数点 + 置信区间 | 同一效应定义、参考组、模型和标准误 |
| DID / 事件研究 | 分组趋势/动态估计点区间 | 平行趋势是假设，前置系数并非自动检验通过 |
| RD | 距离阈值散点/局部拟合与区间 | 带宽、分箱和函数形式；展示阈值附近原始分布 |
| 地理异质性或扩散 | 分级设色地图 + 表/趋势 | CRS、行政边界版本、缺失与零分开；率/绝对量区分 |
| 行政部门协作/政策引用 | 网络图 + 指标表 | 节点/边定义、方向、时间、布局算法，避免布局暗示因果 |

## 选择路径

- 问“谁比谁高”时优先位置/长度，问“如何变化”才用时间线，问“分布如何”用分布图，问“估计量有多不确定”用点区间。
- 若面板之间要比绝对水平，尽量统一刻度；独立 y 轴要显著说明。率与总量分别成图，避免随意双轴；实在需要双轴，明确两轴关系及不能比较的量。
- 柱形从零起点；绝对量的截断会放大差别。系数/差异图可使用聚焦刻度但应显示零线和区间；不要为了放大显著性裁剪区间。
- 对重要组别给出直接数值或名称；分类数量多时分页/小多图，勿依靠几十种颜色区分。
- 有统计模型时，可以同时交付“未经调整的描述图”与“模型调整后估计图”，但必须明确二者不是同一种量。

## 公共政策常见图组

1. `背景`：总体与群体/地区分布；
2. `变化`：政策前后，或长期趋势；
3. `证据`：估计效应与不确定性/适当诊断；
4. `边界`：异质性、稳健性与潜在替代解释。

不是每篇论文都必须有四幅图；每一图都应回答不可被相邻图轻易替代的问题。
