# 出图前复核：三道关

## A 研究与数值（人工 + 独立复算）

- [ ] 来源/版本/观察单位/样本/期间/筛选/权重/分母说明清楚。
- [ ] 缺失与零值分开；异常值和聚合方法可追溯；图中数值与论文/输出表一致。
- [ ] 估计量、模型、参考组、SE/CI/CrI、聚类层级、N 正确；不暗示不存在的因果关系。
- [ ] DID/事件研究/空间或网络图已查对应专项规则；若有多重比较、边界变化等已披露。

## B 视觉（必须实际打开目标文件）

- [ ] 轴、单位、图例、分组、色标、一致性、零线/基准线完整；截断与变换有标识。
- [ ] 按最终刊登或投屏大小检查；中文无缺字、乱码/错形；文字和 CI 没有被裁剪。
- [ ] 色觉友好/黑白可辨；背景/网格不过度干扰；地图缺失与零值可分辨。

## C 交付与可复现

- [ ] 代码能重新生成全部图；不覆写原始数据；随机数（若有）有种子且模拟数据有明确标记。
- [ ] source、transformations、manifest、图注和 alt text 随图交付；保密数据没有泄漏。
- [ ] PDF/SVG/PNG 已逐项打开检查，未把位图误作矢量；满足实际投稿或 PPT 格式要求。
- [ ] 在交付中明确自动检查仅覆盖文件结构，统计正确性和主观视觉质量需独立核验。

可执行 `python scripts/audit_release.py path/to/figure-manifest.json` 做最基本文件与 manifest 检查；其成功输出**不代表**以上人工检查已自动完成。
