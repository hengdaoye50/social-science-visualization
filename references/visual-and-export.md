# 视觉、中文排版与导出

## 默认风格（可覆盖，非期刊强制规则）

- 白或近白底；深灰/黑文字；淡灰参考线；通常主视觉一至两种强调色，不将颜色作为唯一区分方式。折线可用不同线型/标记，组别可用直接标注。
- 字体：优先寻找当前系统已安装的 Noto Sans CJK SC / Source Han Sans SC / 思源黑体 / 微软雅黑 / 苹方等；回退时检查是否丢字或误用日文字形。英文和数字使用兼容字体，保证标点、负号、上标及希腊字母正确。
- 建议单栏宽约 85–90 mm、双栏约 170–180 mm 作为起始设计值；**最终以目标期刊官方说明为准**，不要把经验值谎称强制标准。正文与图内文字大小需以最终缩放后的尺寸检查。
- 标题和图注重点解释单位/范围/估计量；图内避免堆叠长段解释。重要注释直接标在要素附近，不遮挡数据。
- 色彩应兼顾色觉障碍和灰度打印；连续量使用单调色标，存在有意义的零点/正负时才考虑发散色标。颜色顺序和数值对应必须一致。

## 导出格式

- PNG：用于 PPT/公众号及预览；印刷目标通常以目标排版宽度 × 300 dpi（或期刊要求）决定像素，不能仅提高 dpi 参数却维持模糊的上游位图。
- SVG：利于无损缩放和编辑；检查目标软件是否保留字体、连字及符号。若需外发且不能可靠嵌字，可考虑将文字转路径，但会失去文字可编辑/可检索性；同时保留含文本原稿。注意 SVG 可包含嵌入内容和元信息，保密项目需检查。
- PDF：默认矢量交付格式之一；检查中文字体嵌入/转曲、线宽、裁剪框、透明度及软件兼容性。不要把低清 PNG 包进 PDF 后宣称是矢量。
- 图名：`fig-<编号>_<简洁主题>_<语言或场景>.<ext>`；代码、源表/合法获取说明、manifest 与图使用一致编号。
- 每一张独立图保留图注（来源、口径、N、区间说明、处理与变换、模型基准期/组别如相关）和简短 alt text。正文中引用“图 1”等应与文件编号一致。

## Matplotlib 建议

- 用统一的 `rcParams`，按需要设置 `font.family` / `font.sans-serif`，`axes.unicode_minus=False` 仅在确有字体兼容问题时作为回退；若 SVG 需可编辑文本可尝试 `svg.fonttype='none'` 并检查目标机器字体；PDF 嵌字通常设置 `pdf.fonttype=42`，仍需人工检查。
- 显式设置 `figsize`（英寸）和 `dpi`，导出时使用适合的 `bbox_inches='tight'` 并检查裁切；不要让 tight bbox 造成期刊固定尺寸丢失，必要时改用 `constrained_layout` + 手动检查。
- 实际打开 PNG 和 PDF/SVG 检查字号、边距、图例与字形；程序能运行不等于导出可用。
- 每次完成时区分已通过的结构性自动检查与人工视觉/统计检查。
