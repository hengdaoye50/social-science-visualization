# 区域地图与社会网络

## 空间政策/公共治理

- 地名、行政区代码、统计年份和边界版本应一致；市辖区、撤县设区、跨年合并与特殊行政区处理必须留痕。若边界与数据年份不一致，在图注中显著注明。
- 仅使用有授权且来源清晰的地理边界；不能凭空生成轮廓或随意移动坐标。地图制图需采用适当 CRS 与投影，计算面积/距离时不能直接使用经纬度度数。
- 地图的等级分组方法（等距、分位数、自然断点、固定政策阈值）需写明；跨期比较采用相同分级断点，除非明确是各期相对排名。
- 缺失、不可比、未覆盖、零值应分开表示。地图着色用于展现区域模式而非暗示地区个体属性；慎用绝对量分级设色，考虑人均、率或附加表。
- 比较政策扩散时区分“出台时点”“实施时点”“媒体披露时点”，区分存量与新增，不用地图上的相邻形态直接声称扩散机制。
- 涉及领土、边界和其他敏感制图议题，应采用适用的权威地图数据及审图规范；未经核查不得声称地图合规。

## 行政/合作/引用网络

- 明确节点为何物、边代表何种真实关系、是否有向/加权、边生成阈值、观测时间与缺失边处理。网络图布局算法只影响显示位置，不是因果或真实地理距离。
- 同一对象跨图固定编码；节点大小若按中心性/规模缩放，在图例标明映射。图中过密时给出指标表、邻接矩阵、社区/子网络而非强行放大。
- 中心度/中介度/社群划分依赖节点边定义和算法，应记录版本与参数。不可将可见性较高的节点直接描述为制度权威或因果主导者。
- 若包含个人关系、敏感组织互动、未公开行政资料，在展示前审查去标识化与授权。

## 适宜组合

一张地图或网络图通常搭配一个排序表或趋势图：前者看结构，后者让读者准确读取数量或变化。地图/网络的视觉美感不能代替统计比较。
